# hyunjun0210.github.io

## 작품 응원 보드 배포 (Netlify + Functions + Supabase)

1. Supabase에서 프로젝트를 만들고 **SQL Editor**에서 [`supabase/schema.sql`](supabase/schema.sql)을 실행합니다.
2. 저장소를 Netlify에 연결합니다. 빌드 명령은 비워 두고, 게시 디렉터리는 `public`으로 설정합니다(공개 자산만 담긴 폴더). `netlify.toml`이 게시 폴더와 함수 경로를 지정합니다.
3. Netlify 사이트 설정의 환경 변수에 아래 두 값을 추가하고 배포합니다. 값은 Supabase 프로젝트의 API 설정에서 확인할 수 있습니다.
   - `SUPABASE_URL`: 프로젝트 URL
   - `SUPABASE_SERVICE_ROLE_KEY`: 서버 전용 service_role 키. 브라우저 코드나 저장소에 넣지 마세요.
4. 배포된 사이트에서 응원 보드 횟수가 표시되는지 확인하고, 각 작품을 눌러 횟수가 갱신되는지 확인합니다. 다른 기기에서 새로고침해 같은 누적 횟수가 보이는지 확인하면 됩니다.

서버 함수는 세 작품 ID만 허용하고, 응원 한 건씩 `reactions` 테이블에 저장합니다. 횟수는 테이블을 집계해 표시하므로 브라우저 저장소나 함수 메모리에 기록을 보관하지 않습니다. 응원 횟수는 누적 반응 수이며 방문자 수나 1인 1표를 뜻하지 않습니다.

이 저장소에는 기존 응원 기록이나 Blobs 데이터가 없습니다. 따라서 이전할 기록은 없으며, 기존 페이지 콘텐츠와 디자인을 유지한 채 응원 보드와 저장 기능을 추가했습니다.
